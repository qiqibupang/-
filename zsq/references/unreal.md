# Unreal C++ 与蓝图协作

只在 UE 项目的实现、修复、设计或评审中读取本文件。用户当前要求优先于默认分工，不因本规则把已授权的实现转交用户。

## 完成范围与验证边界

- **交给 AI 的 UE 实现和修复，完成后默认只进行与本次改动相关的简单验证；发现问题继续修复并复验，通过后再交付。** 用户明确要求跳过或扩大验证时，以当前要求为准。
- 编译和保存不能代替功能验证。玩法逻辑用短时 PIE 检查关键触发与结果；视觉效果同时检查实际画面；配置或引用改动做对应的读取与加载检查。选能确认结果的最小验证范围，不默认全量测试或新增测试关卡。
- 开工确认目标 `.uproject`、引擎版本、连接状态及待修改资源；保留用户编辑。定位问题需要的运行、日志和截图，以及完成后的聚焦复验，都属于已授权任务的正常步骤，无需逐次询问。
- 验证发现问题时根据证据修复，重复相关检查直到通过；只有缺少必要权限、资料或环境且无法继续时，说明具体阻塞，不把未验证或失败称为完成。
- 交付简述修改、编译/保存状态和实际验证结果，注明仍未覆盖的实质限制。已通过后停止，不自行扩展无关检查。

## 连接与工具

- 默认第三方 [db-lyon/ue-mcp](https://github.com/db-lyon/ue-mcp)，入口 [ue-mcp.com](https://ue-mcp.com/)、[Releases](https://github.com/db-lyon/ue-mcp/releases)、npm `ue-mcp`；项目桥接插件名 `UE_MCP_Bridge`。它不是 Epic 官方 MCP。
- 先复用指向当前工程的连接；未接入时按当前版本说明接入，常规入口 `npx ue-mcp init`，服务参数指向当前 `.uproject`。保留已有配置，不覆盖其他服务，不自动升级正常工作的安装。
- 用 `project(action="get_status")` 确认目标及连接，用 `catalog` 按需查参数；工具前缀不固定。仅安装或写配置不算连接成功。
- 第三方能力不足时，检查并接入当前版本可用的 Epic 官方 MCP。UE 5.8+ 的桥接 `epic_*` 是通过第三方调用官方工具，不等于直连官方服务。核对 Epic 提供方、启用状态、端口、握手及同一工程的只读调用；不可凭名称或工具目录声称接通。
- 第三方窗口检测报阻塞时，先读取状态，再通过可用的官方能力判断是否真被阻塞；普通资产窗口不必要求用户关闭。两边均无法处理且确需用户协助时，说明具体缺口并请求最小操作。不得切换服务绕过真实权限或用户选择。
- C++ 编辑和 UBT 构建可用文件工具与命令行；默认不用界面自动化，遵守入口文件的工具边界。

## 分工与原生系统

- 默认 C++ 规则放 `Plugins/<插件>/Source/` Runtime 模块；编辑器扩展独立 Editor 模块。AI 完成规则、状态、数据及引擎系统之间的连接。用户声明自己制作的蓝图功能只提供接口，不代写；迁移用户已有逻辑到 C++ 需用户同意。
- 原生优先：Chaos 处理物理/破坏，Niagara 处理视觉碎屑和粒子，Enhanced Input 处理输入，UMG 处理 UI，Timeline / Curve 处理少量物件的时间表现；其余按需使用 DataTable、PrimaryDataAsset、AnimNotify、MID、MetaSound / SoundCue、CameraShake / SpringArm、行为树 / StateTree、SaveGame。
- 原生有完整系统就配置使用，只有零件就组合公开 API，确有缺口再自定义。简述影响方案的选择，不罗列无关系统。
- 固定表现可由 C++ 提供默认实现并暴露资源槽；简单蓝图连线由 AI 直接完成。需要反复调手感的曲线、UMG 动画可先搭初版供用户细调。用户明确要求完成的资产、蓝图与表现仍应完成，不因“编辑器点几下”转交。
- 默认不批量生成用户准备自行制作的特效、材质和动画；明确要求 AI 制作时按授权执行。UMG 样式归 UMG 资产，代码传递状态和数值；遵守用户指定的编辑位置。
- 开工简述本轮类、参数和钩子；只有实际需要用户准备素材时才列协作项。收尾按改动规模说明，不强制长表或 PIE 步骤。

## 类、状态与通信

- 按职责、复用及生命周期拆分，沿用现有架构；小功能无需管理器。复用能力用 ActorComponent，确需世界级或跨关卡服务再用 WorldSubsystem / GameInstanceSubsystem。状态转换复杂时才引入状态机。
- GameMode 管权威规则，PlayerController 管输入协调，联网共享状态按需放 GameState / PlayerState。LevelScript 只承担少量当前关卡编排。
- 资源和默认值变体用蓝图子类；明显的代码行为差异才新增 C++ 子类。高频生成销毁或性能证据支持时才用对象池；回收须重置碰撞、速度、计时器、订阅和状态。
- 跨对象读取、存档、参与规则的状态放 C++；单个蓝图的表现临时状态可放蓝图。避免硬编码蓝图路径或 FindFunction 反向依赖；用 TSubclassOf、软引用或资产属性配置。
- 共用参数组用 BlueprintType 结构体，多套配置按需使用 PrimaryDataAsset。稳定互斥模式用枚举，可扩展层级分类用 GameplayTag；不因跨对象使用就替换枚举。
- 已知类型直接调用；多类型共享能力再用接口；一对多蓝图通知用动态多播委托和 BlueprintAssignable。
- 组件在构造函数 CreateDefaultSubobject，根组件 SceneRoot。默认碰撞、Tick、可见性、Overlap / Hit 等直接设置为游戏应有默认值，不在 BeginPlay 偷换默认状态。
- 必要的运行时切换用明确命名的函数，属性注释与交付说明写明触发时机和变化。修改原生默认值时处理相关蓝图覆盖，不假定已有 CDO 自动更新。
- 生命周期重写调用 Super；委托、计时器与预览对象在适当生命周期清理。样条按距离推进；真实受力用原生物理，精确轨迹按需求选运动组件或显式移动；MID 创建后缓存复用。

## 蓝图接口与命名

- 配置按用途用 EditAnywhere / EditDefaultsOnly / EditInstanceOnly；运行时状态 VisibleAnywhere、BlueprintReadOnly，修改通过 Setter 并通知变化。生成参数可用 ExposeOnSpawn 与延迟生成。
- 普通入口 BlueprintCallable，纯查询 BlueprintPure、const；有副作用或昂贵的 const 调用显式 BlueprintPure=false。仅子蓝图需要的放 protected，外部调用放 public，内部步骤不暴露。
- 对外函数、组件、变量、类型及枚举值设置中文 DisplayName。C++ 标识符沿用英文 PascalCase 和 UE 类型前缀，布尔 bXxx；资产用 BP_ / AC_ / WBP_ / DA_ / E_ / ST_ / BI_ 加中文业务名。
- 用户给定名称直接用；已授权自行命名时按中文业务含义确定，不重复询问。只有名称涉及未明确的业务语义时再问。
- 函数和纯函数前缀 F_，无返回值事件 CE_，委托 ED_；带返回值的 NativeEvent / ImplementableEvent 实际是函数，仍用 F_。
- 每个类的暴露变量统一在去除 BP_ 等前缀的中文业务 Category；共用基类用共同业务名。事件分组与变量分类分别管理。
- 所有暴露给编辑器直接调用的事件和函数（C++ CallInEditor、蓝图勾选“在编辑器中调用”的入口）统一归入“编辑器操作”分类，集中显示在详情面板最顶部、先于业务参数与 Transform 等原生分类；继承入口也遵守。不得按业务类别分散按钮，不能只靠分类名称前缀假定置顶。普通运行时事件不因此新增 CallInEditor。
- 业务类别用 PrioritizeCategories 前置，排在“编辑器操作”之后；类内用连续 DisplayPriority / 必要的 DisplayAfter。原生元数据不足时，在 Editor 模块用 IDetailCustomization::SortCategories 和 SetSortOrder 保证最终顺序。修改时检查 C++ 与蓝图入口并做一次实际面板检查，保留原有函数名、逻辑、连线及变量分类。
- UE 数值直接使用 API 原生单位：距离 cm、速度 cm/s、时间 s、角度为度。自定义字段不加 Units / ForceUnits，不在显示名加单位后缀，不为显示乘除 100，不改全局或引擎原生单位设置。
- 每个协作入口用注释说明触发时机、前后固定步骤、参数和推荐用途，不用 BlueprintInternalUseOnly 隐藏给用户的接口。

## 可重写与附加事件

- 只暴露本轮实际有规则替换、表现接入或通知价值的入口，流程可按需要拆成积木函数；不为未来猜想扩展接口。积木函数校验状态，非法调用返回并给明确 Warning。
- 可替换步骤用 BlueprintNativeEvent，名称 CE_重写_业务名 / F_重写_业务名；注释明确默认实现及“不调父类即替换，调父类保留”。
- 仅追加效果用 BlueprintImplementableEvent，名称 CE_附加_业务名；注释明确“无默认实现，不替换固定流程，不需要调用父类，空着不影响功能”。有两种实际需求时同时提供，只适合一种时不凑双入口。
- 非编辑器直接调用的事件分组 Category 为“业务名|可重写事件”和“业务名|附加效果事件”；启用 CallInEditor 的入口遵守上面的“编辑器操作”集中置顶规则。固定调度承担状态校验、唯一触发、重入保护与收尾，独立调用两种入口；附加事件不能仅写在可被替换的 _Implementation 中。
- 明确固定步骤、可替换步骤和顺序；蓝图 Delay / Timeline 不会让同步 C++ 自动等待。回调后按需处理销毁和状态变更，不声称附加事件完全隔离其主动副作用。
- 优先沿用适合的原生入口；修改旧接口保持兼容，不批量重命名无关事件。已发布属性不随意删除；必要改名用 CoreRedirects。

## 暴露即上图与资源保护

- 新增或修改的协作函数、事件、委托通过 UE-MCP 放到对应派生蓝图。普通函数放调用节点，事件放真实继承重写节点，有返回值入口建函数图，委托放绑定节点；不创建同名 Custom Event 冒充重写。
- 在现有空白处按可重写、附加、调用、查询分组并加注释，保持间距；普通调用节点默认不连。新放的 NativeEvent 接好父类、参数和返回值以保留默认行为；附加事件留空。用户原有连线、布局及父类调用习惯不变，重复执行不重复添加。
- 修改前确认目标继承关系和未保存状态，保留受影响资产的可恢复副本。受保护资产只读，不能临时改了再撤回；误改应停止告知，恢复前确认不会丢失用户工作。
- 修改后编译并保存受影响蓝图，再按首节进行简单验证。收尾按需列出蓝图、节点及固定流程；无法上图要如实说明，不能以 C++ 声明替代已完成资产修改。

## 编译、目录与交付

- 只改 cpp 函数体可用 Live Coding；反射头文件、类布局、构造默认值等变更采用完整编译，并处理已有蓝图覆盖。重启前妥善保存，不强关；DLL 占用不能靠改名或删除绕过。不可在 PIE 中编译或重实例化蓝图。
- Runtime 与 Editor 依赖分开，插件版本匹配目标引擎；需要提供纯蓝图用户可用的插件发行包时，用 BuildPlugin 产出 Binaries，不默认打包。
- **派生 BP / ABP / WBP 放项目 Content（/Game/），不放插件 Content；新增业务文件夹用中文**，如 Content/玩法/蓝图、Content/玩法/界面、Content/玩法/曲线。Content、Plugins、Source 等固定目录名不变。
- 资产迁移使用 UE 原生移动/重命名并修复引用和重定向器，编译保存相关资产；不直接剪切 uasset。修复关卡引用后做对应的简单加载或运行检查。
- 交付实际改动、可调入口、资源位置、必要的用户素材操作和编译/保存结果。接口较多时可列表说明 C++ 名、中文节点名、类型、用途、是否上图。遵守首节验证范围，通过后交付，不扩展无关测试。
