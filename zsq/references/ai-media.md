## 图片与视频 AI 生成流程

适用于所有 AI 图片、视频的生成、编辑、重生成。仅查看、分析、播放、提供关键词、普通裁剪转码不适用。流程为：确认必要参数 → 整理提示词 → 调用 → 自查 → 交付。用户已明确提供或授权沿用的参数不重复询问。

### 1. 访谈

- 下表用于发现缺失参数；只询问会实质改变结果且尚未明确的项目，并等待回答；选项预选、上下文推测、用户沉默、超时或只答一部分都不算确认。只要仍有会改变结果的未答项，就暂停生成、编辑、上传与付费调用。
- 普通生成需求不触发 grilling；只有用户要求追问或压力测试时才使用。
- 同一会话内的修改或重生成，不重复问全表：先列出「沿用参数表」（上次每一项的实际值）加「本次变化项」，让用户一次确认；用户说"沿用"只覆盖表中明确列出的项，新增或改动的项仍要问。切换到新任务则重新访谈。
- 涉及费用时先查当前服务实际支持的档位与价格，给出本次估价并含重试预算（按下方重试上限计算）；不凭记忆承诺。

| 项目 | 图片 | 视频 |
|---|---|---|
| 模型 | 必问 | 必问 |
| 数量 / 时长 | 张数 | 时长、帧率 |
| 画幅 | 比例 | 比例、清晰度 |
| 质量档位 | 分辨率或质量档 | 清晰度档 |
| 生成模式 | 文生图 / 图生图 / 局部重绘 / 扩图 | 文生视频 / 图生视频 / 首尾帧 / 延长 / 视频转视频 |
| 参考素材及其角色 | 构图 / 风格 / 主体 / 背景 参考 | 首帧 / 尾帧 / 动作 / 风格 参考 |
| 主体与造型 | 保留项、可变项 | 同左 |
| 动作与节奏 | 姿态 | 动作顺序、速度、循环/首尾规则 |
| 镜头与空间关系 | 构图、视角 | 机位、运动、角色位置朝向比例是否锁定 |
| 背景与修改范围 | 改哪里、不改哪里 | 同左 |
| 风格与画面文字 | 画风、是否有文字/水印 | 画风、字幕/文字 |
| 声音 | — | 有无、类型、是否对口型 |
| 禁止项 | 不允许出现的元素、动作 | 同左 |
| 输出 | 格式、保存位置、是否需要 seed 复现 | 同左 |

### 2. 整理提示词

- 访谈结束后由当前助手把用户答案整理成适合目标模型的最终提示词，明确写出保留项、动作顺序、禁止项、镜头约束、循环约束、每个参考素材的角色。
- 不把未理解的用户原话直接转发；不在调用中静默添加未确认的动作、镜头、参数。调用前把最终提示词与参数一并展示给用户。

### 3. 自查

- 生成后对照访谈表逐项核对，不只看整体印象。图片查构图、主体完整性、指定修改区域、未指定区域是否被误改、张数与画幅、文字与水印、禁止项。视频另查动作顺序与节奏、镜头与空间关系、声音、时长、帧率、首尾衔接。
- 视频必须实际抽帧：用 ffmpeg 按开头、中段、结尾和每个关键动作时间点抽成图片再逐张查看，首尾循环时把首帧与末帧并排比对；不能只凭时长、文件存在或模型返回说明判定通过。
- 任一项不符即按偏差改写提示词并重新生成或编辑。同一硬约束最多重试 3 次；仍不达标时停下，向用户说明具体失败点、已试过的写法，询问是接受替代方案、调整约束还是换模型，不再继续消耗。
- 不能只报告不符合就交付，也不能把未验证的推测说成通过。

### 4. 交付

- 自查通过后交付，并同时报告：实际模型与全部参数、seed、最终实际使用的提示词与负面词、参考素材及其角色、保存路径、实际花费、仍存在的限制。让用户下次微调有起点。
- 动作与镜头要求以本次指令为准，不把单次要求固化为默认值。例如用户指定"仅呼吸"的 Idle 就不加攻击、眨眼等动作；要求锁定空间关系时固定机位、角色位置、朝向和比例；要求首尾循环时，模型支持则用同图或明确首尾约束，并按第 3 步实际比对衔接。
